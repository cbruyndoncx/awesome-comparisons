### Description
Devstral 2 is Mistral's coding-agent model family, released with Devstral 2 and Devstral Small 2. Devstral 2 is a 123B dense model with a 256K context window; Devstral Small 2 is a 24B model intended for API use and local deployment on suitable hardware. Both target end-to-end software-engineering tasks and integrate with Mistral Vibe.
