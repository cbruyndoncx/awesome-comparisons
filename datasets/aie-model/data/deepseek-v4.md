### Description
DeepSeek V4 is the current DeepSeek API family as of April 2026. The API exposes `deepseek-v4-pro` and `deepseek-v4-flash` through OpenAI Chat Completions and Anthropic-compatible interfaces. The older `deepseek-chat` and `deepseek-reasoner` names point to V4 variants during the migration period and are scheduled for discontinuation.
